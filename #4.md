## TAREA 3: WebSocket Server Central [DIVIDIDA EN SUBTAREAS]

**Objetivo:** Servidor que permita sincronización en tiempo real entre dispositivos

### SUBTAREA 3.1: Estructura del WebSocket Server [30 min]
**Agente:** `flutter-backend-solutions`
**Instrucciones para el agente:**
1. Crear archivo `lib/data/datasources/remote/websocket_server.dart`
2. Implementar clase `WebSocketServer` con:
   - Método `startServer({String host = '0.0.0.0', int port = 8080})`
   - Lista de clientes conectados: `List<WebSocketSocket> _clients`
   - Método `broadcast(Map<String, dynamic> message)` 
3. Usar `shelf_web_socket` package
4. NO implementar lógica de negocio todavía, solo la infraestructura

**Entregable:**
- Archivo `websocket_server.dart` con estructura básica del servidor
- Compilación sin errores
- Servidor puede iniciar y aceptar conexiones

**Validación:**
- [ ] Archivo creado sin errores de compilación
- [ ] Servidor inicia sin crash

### SUBTAREA 3.2: Modelos de Mensajes WebSocket [20 min]
**Agente:** `flutter-backend-solutions`
**Instrucciones:**
1. Crear archivo `lib/data/models/websocket_message.dart`
2. Definir modelos:
   ```dart
   class WSMessage {
     final String type; // 'investment', 'session', 'user', etc.
     final String action; // 'create', 'update', 'delete'
     final Map<String, dynamic>? data;
   }
   ```
3. Definir tipos de mensajes:
   - `investment_created`, `investment_updated`, `investment_deleted`
   - `session_started`, `session_updated`, `session_ended`
   - `user_login`, `user_logout`
   - `project_updated`

**Entregable:**
- Archivo con modelos de mensajes
- Todos los tipos de mensajes definidos

**Validación:**
- [ ] Modelos creados y documentados
- [ ] Todos los tipos de mensajes necesarios definidos
