# 3. Plan de Implementación - Modo Multi-Dispositivo

## Objetivo
Implementar la funcionalidad multi-dispositivo para que 70+ usuarios puedan acceder simultáneamente desde sus navegadores web a la aplicación ejecutada en una PC/Mac central, con sincronización en tiempo real de inversiones.

### TAREA 5: Detección de IP Local [PRIORIDAD MEDIA]
**Agente sugerido:** `general-purpose` o `flutter-dev-expert`
**Tiempo estimado:** 1-2 horas
**Dependencias:** Tarea 2

#### Pasos:
1. Implementar detección automática de IP local:
   - Usar `dart:io` para obtener interfaces de red
   - Filtrar interfaces WiFi (usualmente `192.168.x.x` o `10.x.x.x`)
   - Mostrar IP en dashboard del admin

2. Crear `lib/core/utils/network_utils.dart`:
   ```dart
   import 'dart:io';
   
   class NetworkUtils {
     static String? getLocalIPAddress() {
       for (var interface in NetworkInterface.list(includeLinkLocal: false)) {
         for (var addr in interface.addresses) {
           if (addr.type == InternetAddressType.IPv4) {
             final ip = addr.address;
             if (ip.startsWith('192.168.') || 
                 ip.startsWith('10.') ||
                 ip.startsWith('172.')) {
               return ip;
             }
           }
         }
       }
       return null;
     }
     
     static String getServerURL() {
       final ip = getLocalIPAddress() ?? 'localhost';
       return 'http://$ip:8080';
     }
   }
   ```

3. Mostrar IP en pantalla de bienvenida y dashboard admin:

## Notas Importantes

1. **Dependencias externas**: Verificar que todos los paquetes en `pubspec.yaml` soporten web. Paquetes problemáticos comunes:
   - `path_provider` → Usar alternativas web
   - `sqlite` → Funciona en web con WASM
   - `shared_preferences` → Funciona en web

2. **Limitaciones del navegador**:
   - Algunas características de Flutter pueden no funcionar idénticas en web
   - Probar extensivamente en Chrome y Safari
   - Considerar respaldo para navegadores antiguos

3. **Rendimiento**:
   - 70 usuarios simultáneos pueden saturar una PC normal
   - Considerar hardware mínimo: 8GB RAM, CPU i5 o superior
   - Monitorear uso de recursos durante pruebas

4. **Seguridad**:
   - La red WiFi local debe tener contraseña WPA2
   - Considerar usar certificado SSL (auto-firmado localmente)
   - No exponer datos sensibles sin cifrado
